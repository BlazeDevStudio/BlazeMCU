Prepare compatible firmware

Reference instructions

Arduino IDE: Select the correct ESP board, flash size and build options, then use Sketch → Export Compiled Binary.

Arduino CLI: Install the matching core and use arduino-cli compile --fqbn <board> --export-binaries sketch/.

PlatformIO: Build the environment matching the board. The app binary is typically found under .pio/build/<env>/firmware.bin.

ESP-IDF (ESP32): Run idf.py set-target esp32 and idf.py build. App images are not merged flash images. ESP8266 uses a different build and boot process.

Safety & recovery

ROM serial download mode may allow re-flashing a damaged board (typically GPIO0 LOW during reset); the USB interface, power and flash offsets are board-specific. A factory partition does not guarantee automatic fallback.

Never treat a matching filename, I²C address, or GPIO capability as a guarantee of hardware compatibility. Consult the board manufacturer's pinout before connecting loads.
