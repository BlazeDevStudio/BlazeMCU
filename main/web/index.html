How to prepare a .bin

Arduino IDE: Select the exact ESP32 board, flash size and partition scheme. Use Sketch → Export Compiled Binary. Do not upload .ino directly.

Arduino CLI: Install esp32 core, select the FQBN, then run arduino-cli compile --fqbn esp32:esp32:esp32 --export-binaries path/to/sketch.

PlatformIO: Build a matching platform = espressif32 environment. The application image appears under .pio/build/<env>/firmware.bin.

ESP-IDF: Run idf.py set-target esp32, then idf.py build. Use the application .bin for compatible OTA slots; a merged full-flash image is not interchangeable with an OTA application image.

ESP32 builds use ESP-IDF; ESP8266 builds use a separate PlatformIO/Arduino core toolchain. Select the correct chip and board before compiling. ESP32 factory/OTA layouts are not interchangeable with ESP8266 flash layouts.

4 MB flash and partition compatibility are mandatory for the current reference boards. A factory partition does not automatically make a boot failure recoverable without a serial flashing path.

For faults, use the chip-specific ROM serial download mode (GPIO0 LOW at reset where appropriate) and esptool to reflash an authorized recovery image. Verify your specific board's buttons and wiring first.
